# Проект «Комментарии»

Интерактивное приложение для оставления комментариев: регистрация и вход,
лента комментариев с лайками, ответами на другие комментарии и защитой от
XSS-инъекций.

🔗 **Демо / репозиторий:** https://github.com/micha01-bit/Comments-feed-Dom/

## Возможности

- **Просмотр комментариев** — список загружается с сервера при запуске,
  во время загрузки показывается индикатор «Пожалуйста подождите…».
- **Регистрация и авторизация** — комментарии может оставлять только
  авторизованный пользователь. Имя подставляется в форму автоматически
  (поле только для чтения).
- **Добавление комментариев** — с валидацией (имя и текст не короче 3 символов)
  и индикатором отправки.
- **Лайки** — можно лайкать и снимать лайк, счётчик обновляется с анимацией.
- **Ответ на комментарий** — клик по комментарию подставляет в форму ввода
  текст вида `Имя: текст комментария`.
- **Сохранение сессии** — токен и имя пользователя хранятся в `localStorage`,
  после перезагрузки страницы вход сохраняется.
- **Обработка ошибок**:
  - ошибка сети → «Нет интернета. Попробуйте снова»;
  - статус `400` → «Имя и комментарий должны быть не короче 3-х символов»
    с подсветкой полей;
  - статус `500` → автоматический повтор запроса (до 3 попыток с задержкой).
- **Защита от XSS** — весь пользовательский ввод экранируется функцией
  `sanitizeHtml` перед отправкой и рендером.

## Стек технологий

- **HTML5**, **CSS3** — вёрстка и стили
- **JavaScript (ES6+)** — вся логика, ES-модули
- **Fetch API** — запросы к серверу, промисы, обработка ошибок
- **Webpack** — сборка проекта (результат в `dist/main.js`)
- **localStorage** — сохранение сессии пользователя
- Бэкенд — учебный API [wedev-api.sky.pro](https://wedev-api.sky.pro)

## API

База данных курса хостится по адресу:

- Получение комментариев: `GET https://wedev-api.sky.pro/api/v2/evgeniy-bespalov/comments`
- Добавление комментария: `POST https://wedev-api.sky.pro/api/v2/evgeniy-bespalov/comments`
  (заголовок `Authorization: Bearer <token>`)
- Авторизация: `POST https://wedev-api.sky.pro/api/user/login`
- Регистрация: `POST https://wedev-api.sky.pro/api/user`

## Как запустить

### Вариант 1 — без сборки

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/micha01-bit/Comments-feed-Dom.git
   ```
2. Откройте `index.html` в браузере
   (если бандл уже собран в `dist/`, всё заработает сразу).

### Вариант 2 — с пересборкой (webpack)

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Соберите проект:
   ```bash
   npm run build
   ```
3. Откройте `index.html` в браузере.

## Как пользоваться

1. Откройте страницу — комментарии загружаются автоматически.
2. Чтобы оставить комментарий, войдите по ссылке «войдите»
   или зарегистрируйтесь (имя, логин, пароль).
3. Введите текст и нажмите «Написать».
4. Кликните по иконке сердца — поставите лайк.
5. Кликните по тексту комментария — он подставится в форму как цитата для ответа.
